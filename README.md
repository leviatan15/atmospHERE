atmospHERE

## Overview

Interactive weather application built with:

- Node.js
- Express
- Vanilla JavaScript
- EJS
- weather-data API

## Features

- Search historical weather by city
- Valid hourly weather data (based on source data availability)
- Hourly navigation
- Daily overview chart
- Dynamically built SVG graph
- Interactive Globe with country highlighting
- Dynamic weather backgrounds
- Custom animated weather icons
- Valid Moon phase display
- Responsive design
- Input validation
- Autocomplete search
- Tech Stack

## Installation/Usage

A: Run locally (requires own API key -> visualcrossing.com)

1. Clone the repository
git clone <repository-url>
cd atmospHERE
2. Install dependencies
npm install
3. Create a .env file
API_KEY=your_api_key_here
4. Start the application
node(mon) index.js
5. Open in browser
6. Enjoy!
